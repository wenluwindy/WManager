# 相机工具使用说明

> 基于 `Assets/Scripts/WManager/Camera/` 当前源码。
> 提供三种相机控制器：`RoamCameraController`（漫游）、`FirstPersonController`（第一人称）、`SurroundingCamera`（环绕），以及 `ICameraController` 接口。
> 同时包含 `MiniMap` 小地图工具。

## 1. 能力概览

| 控制器 | 用途 | 主要能力 |
|---|---|---|
| `RoamCameraController` | 场景漫游/编辑器视角 | 键盘移动、滚轮缩放、右键旋转、范围限制、`Focus` 插值 |
| `FirstPersonController` | 第一人称玩家 | 移动、跳跃、蹲伏、重力、头部晃动、脚步音效 |
| `SurroundingCamera` | 围绕目标旋转 | 距离、阻尼、俯仰角限制、`ChangeTarget` |
| `MiniMap` | 小地图 | 世界 X/Z 坐标映射到 UI `RectTransform` |

## 2. RoamCameraController

### 2.1 操作

- W / S / A / D / Q / E：前/后/左/右/下/上移动。
- 鼠标右键拖动：旋转视角。
- 鼠标滚轮：拉近/拉远。
- Shift：加速（`boost`）。

### 2.2 关键 Inspector 配置

| 字段 | 说明 |
|---|---|
| `toggle` | 总开关 |
| `isRangeClamped` + `xMin/xMax/yMin/yMax/zMin/zMax` | 是否限制活动范围及边界 |
| `translateSpeed` / `boost` | 移动与加速速度 |
| `positionLerpTime` / `rotationLerpTime` | 位置/旋转插值时间 |
| `mouseMovementSensitivity` | 视角旋转灵敏度 |
| `invertScrollDirection` / `invertY` | 反向 |
| `verticalLimitMin/Max` | 视角垂直旋转范围 |

### 2.3 公开方法

```csharp
roamCamera.SetFromTransform(targetTransform);   // 用 Transform 状态覆盖当前
roamCamera.UpdateTransform(targetTransform);   // 把当前状态写回 Transform
roamCamera.Translate(Vector3);                 // 平移
roamCamera.LerpTowards(targetState, posLerpPct, rotLerpPct);
roamCamera.ResetCamera();                       // 重置回初始状态
roamCamera.Focus(position, rotation, duration);// 在指定时长内插值到目标位姿
```

> `Focus` 内部使用 DOTween 在 `duration` 秒内平滑过渡；可被新的 `Focus` 调用取消。

## 3. FirstPersonController

适合玩家角色视角，需要把脚本挂在角色 GameObject 上，并配置：

- `mRigidBody`：角色刚体。
- `capsuleCollider`：胶囊碰撞体。
- `playerCamera`：玩家相机。
- `head`：头部节点（用于头部晃动）。
- 音效：`footStepSounds / jumpSound / landSound`。
- 输入相关：`enableMouseLook / mouseSensitivity / verticalRotationRange`。
- 移动：`walkSpeed / runSpeed / crouchSpeed / jumpPower / gravityMultiplier`。
- 头部晃动：`headbobFrequency / headbobHeight / headbobSwayAngle / jumpLandJerkIntensity`。
- 行为开关：`enablePlayerMovement / enableCrouch / enableHeadbob / enableAudioSFX / hideCursorOnStart / rightMouthButtonDrived`。

公开方法：

```csharp
fpc.RotateCamera(rotation, snap: bool); // 直接施加视角旋转（snap 决定是否截断）
```

> 推荐直接使用目录中的 `FirstPersonController.prefab`，自行配置后即可使用。

## 4. SurroundingCamera

围绕目标 `Transform` 旋转：

```csharp
surroundingCamera.ChangeTarget(newTarget);
```

Inspector 字段：

- `RotationMode`（鼠标按键选择）。
- `xSpeed / ySpeed`：旋转速度。
- `yMinLimit / yMaxLimit`：俯仰角限制。
- `distance / minDistance / maxDistance`：相机与目标距离。
- `needDamping`：是否启用阻尼。

## 5. ICameraController

统一抽象相机控制器接口，方便业务侧替换实现。

## 6. MiniMap

将世界坐标 `X/Z` 按场景边界映射到 UI `RectTransform` 的 `anchoredPosition`：

1. 场景中以 `z` 正方向为上、`x` 正方向为右。
2. 配置 `leftBottom`、`rightTop` 两个 Transform。
3. 配置目标物体 `target3d` 与其 UI Icon `target2d`，以及小地图 `mapRt`。
4. 比例：`ratioX = mapRt.rect.width / (rightTop.position.x - leftBottom.position.x)`，`ratioY` 类同。
5. 每帧计算 `target2d.anchoredPosition = (horizontal * ratioX, vertical * ratioY)`，锚点设为左下角。

```csharp
// 伪代码：每帧刷新
Vector3 worldPos = target3d.position;
float x = (worldPos.x - leftBottom.position.x) * ratioX;
float y = (worldPos.z - leftBottom.position.z) * ratioY;
target2d.anchoredPosition = new Vector2(x, y);
```

> 推荐在 `LateUpdate` 中调用，避免与角色移动产生错位。

## 7. 注意事项

- `RoamCameraController` 同时支持 `Input Manager` 与新 Input System（`ENABLE_INPUT_SYSTEM`），可在工程中切换。
- `FirstPersonController` 内置 `mRigidBody.linearVelocity`，对应 Unity 6 物理 API。
- `MiniMap` 的 `leftBottom/rightTop` 应放在场景底层，Y 保持一致；否则高度差会导致坐标漂移。
- 多个相机同时启用时建议为相机分配独立 Layer，避免相互裁剪/遮挡。
